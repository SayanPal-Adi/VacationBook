# Frontend Guidelines

- Use semantic HTML5 elements.
- Keep page-specific JavaScript in separate files where practical.
- Keep styles organized by shared components or page areas.
- Use CSS variables for palette, spacing, typography and border radius.
- Avoid inline event handlers; attach listeners from JavaScript.
- Validate forms in the browser for usability, but repeat validation on the server.
- Treat all browser-provided values as untrusted.
- Provide responsive layouts and accessible focus states.
- Do not place secrets, privileged database keys or authorization logic in frontend code.
