# Project Scope

## In scope
VacationBook is a web-based accommodation discovery and booking demonstration with a Flask backend, HTML/CSS/JavaScript frontend, Supabase PostgreSQL database and Railway deployment target.

## Explicit constraints
- Payments are simulated.
- No real card or bank data should be collected.
- Availability and pricing decisions are made by the server.
- Users may access only their own customer records unless an authorized admin role permits broader access.

## Out of scope
Real payment processing, external travel inventory synchronization, airline reservations, native apps and production-grade financial settlement.

## Change control
A new feature should be added only after documenting its user value, data impact, security impact and testing requirements.
