# Project Overview

## Product
**Name:** VacationBook

VacationBook is a web application intended to make discovering and booking vacation accommodation straightforward. The product should feel polished, trustworthy and easy to use.

## Objectives
1. Let visitors discover accommodation.
2. Present property information clearly.
3. Support account creation and authentication.
4. Allow signed-in users to create, view and cancel bookings according to business rules.
5. Demonstrate a complete simulated checkout flow.
6. Provide administrative tools for managing platform content.

## Target users
- Travellers researching accommodation
- Registered customers managing trips
- Administrators managing listings and reservations

## Product principles
- Clear pricing and booking details
- Responsive, accessible interfaces
- Secure handling of credentials and sessions
- Consistent validation and useful error messages
- No real payment processing in this version

## Success criteria
- A user can complete the core browse-to-confirmation journey.
- Booking rules are enforced on the server.
- Data persists in PostgreSQL.
- The application can be deployed to Railway.
- Critical user journeys have repeatable tests.
