# Feature Catalogue

## Customer-facing
- Landing page and featured stays
- Property search
- Filters for destination, dates, guest count and price range
- Property detail page
- Account registration and login
- Profile management
- Booking creation
- Booking history and details
- Booking cancellation where permitted
- Simulated checkout
- Booking confirmation

## Administration
- Admin authentication/role authorization
- Property creation and editing
- Publish/unpublish or archive listings
- Booking overview

## Quality features
- Responsive design
- Form validation and clear feedback
- Empty, loading and error states
- Secure password hashing
- Server-side authorization
- Structured logging

Feature status should be tracked in the issue tracker or updated here as implementation progresses.
