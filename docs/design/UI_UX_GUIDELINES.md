# UI/UX Guidelines

## Visual direction
**Luxury minimal — Ivory + Navy**

Suggested starting palette (adjust after visual review):
- Ivory background: `#F7F4ED`
- Warm white surface: `#FFFEFA`
- Deep navy: `#14243A`
- Muted navy: `#34465D`
- Soft border: `#E5E0D6`
- Accent: restrained brass `#B69A68`

## Typography
Use a refined display typeface for major headings and a highly legible sans-serif for body text. Keep font loading resilient with system fallbacks.

## Layout
- Use generous whitespace and a consistent spacing scale.
- Use a clear content width and responsive grid.
- Keep primary actions visually distinct.
- Use consistent image ratios for property cards.
- Ensure forms are easy to scan and complete.

## Interaction
- Provide visible hover, focus, disabled, loading and error states.
- Use labels and helpful validation messages.
- Confirm destructive actions such as cancellation.
- Make simulated payment unmistakably a demo.

## Accessibility
- Use semantic landmarks and heading order.
- Provide descriptive alt text.
- Ensure keyboard navigation and visible focus.
- Maintain sufficient text/background contrast.
- Do not communicate status through colour alone.
