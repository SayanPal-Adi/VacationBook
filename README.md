# VacationBook

VacationBook is a portfolio-grade, commercial-style vacation booking platform.

## Project decisions
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python Flask
- **Database:** Supabase PostgreSQL
- **Deployment target:** Railway
- **Payments:** Simulated payments only; no real money is collected
- **Visual direction:** Luxury minimal — ivory and navy

## Planned capabilities
- Browse and search vacation stays
- View property details, images, amenities and availability
- Register, sign in and manage a user profile
- Create and manage bookings
- Simulate a payment and display a booking confirmation
- Provide an administrative interface for managing listings and bookings

These are planning targets. Update this document as features are implemented.
